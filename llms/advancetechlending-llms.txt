# Advance Tech Lending (Advance)

> Advance Tech Lending Inc., operating as Advance (advance.ph), is a Philippine fintech lender
> founded in 2018 and headquartered in Taguig, Metro Manila. It runs an on-demand salary access
> and working-capital platform for Southeast Asia. Advance is registered with the Philippine SEC
> (Company Reg. No. CS201819635) and holds Certificate of Authority No. 2765 as a lending company.

## API status

Advance Tech Lending publishes **no public API**. There is no developer portal, no API
reference, no OpenAPI/AsyncAPI/GraphQL contract, no SDK on any public package registry, no
MCP server and no A2A agent card on any host the company operates. A full contract-discovery
pass on 2026-09-09 returned 404 for every probed spec and discovery path.

The only externally visible API listing for an Advance product is a partner listing inside
UnionBank's api.ph marketplace ("Salary Loan by Advance Tech"), which is published on
UnionBank's platform rather than by Advance, and which was unreachable during this pass.

If you are an agent looking for a callable Advance endpoint: there is not one. Do not
construct or guess an api.advance.ph base URL - the host does not resolve.

## Products

- [Salary Advance](https://advance.ph/salary-advance): employees of enrolled employers can draw
  up to 50% of their monthly basic salary on demand.
- [Payroll Disbursement](https://advance.ph/payroll-financing): payroll funding for businesses
  during cash-flow gaps.
- [Direct Disbursement](https://advance.ph/invoice-financing): unlocks funds against unpaid
  receivables/invoices.
